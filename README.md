# Charan Portfolio

Personal marketing portfolio of **R. Charan Shankar Naidu**: a single-page, studio-style site.

- `index.html` contains all markup, styles and scripts (no build step)
- `images/` holds the photos used on the page (WebP)
- `fonts/` holds the Rajdhani and Inter font files, served locally
- `js/lenis.min.js` is the smooth-scroll library (Lenis, MIT), desktop only

**Highlights:** interactive particle portrait, RGB-glitch scroll reveal, counting impact stats, parallax case studies, pinned horizontal gallery with lightbox, live Dubai/Bangalore clocks, dark impact scene, scroll-reactive marquee, curtain-reveal footer.

## Publish with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.
