# Charan Portfolio

Personal marketing portfolio of **R. Charan Shankar Naidu**: a single-page, studio-style site.

- `index.html` contains all markup, styles and scripts (no build step)
- `images/` holds the photos used on the page

**Highlights:** interactive particle portrait, RGB-glitch scroll reveal, counting impact stats, parallax case studies, pinned horizontal gallery with lightbox, live Dubai/Bangalore clocks.

## Publish with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.
